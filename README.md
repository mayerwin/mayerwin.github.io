# mayerwin.github.io

Personal GitHub Pages root and redirect router for Erwin Mayer ([@mayerwin](https://github.com/mayerwin)).

## Purpose

This repository provides seamless URL redirects for projects that previously resided under `https://mayerwin.github.io/<project>/` and have moved to dedicated GitHub organizations:

- `https://mayerwin.github.io/sonora-live/*` &rarr; `https://sonora-live.github.io/*`
- `https://mayerwin.github.io/Tidesight/*` &rarr; `https://tidesight-analytics.github.io/*`
- `https://mayerwin.github.io/` &rarr; `https://www.erwinmayer.com/`
